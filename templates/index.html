Common questions

Is BlindSpot a hacking tool?

No. BlindSpot only runs passive, read-only checks. It never tries to break in, and it's designed for websites you own or have explicit permission to test.

Do I need to know security to use it?

No. Every result is written in plain English, with a simple severity label and step-by-step fix suggestions.

What does the score mean?

It's the BlindSpot Basic Security Score — based only on the checks we run. It's a starting point for your security journey, not a full audit.

What if a website isn't mine?

Don't scan it. BlindSpot is for authorized checks only — your own websites or ones you have written permission to test.
